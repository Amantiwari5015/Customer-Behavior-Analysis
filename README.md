# Customer Behavior Analysis

## Overview

This project focuses on analyzing customer behavior using Python, MySQL, and Power BI. The objective is to transform raw customer data into meaningful insights, identify trends and patterns, and support data-driven business decisions.

The project covers the complete data analytics workflow, from data loading and cleaning to SQL analysis, dashboard development, reporting, and presentation creation.

## Dataset

The project uses a customer behavior dataset containing information relevant to customer preferences, purchasing patterns, and engagement.

- **Format:** CSV / Excel
- **Processing:** Data loading, exploration, cleaning, and transformation using Python.

- **Python:** Data loading, data cleaning, and exploratory data analysis (EDA)
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization

## Project Workflow

### 1. Data Loading
- Imported the dataset into Python.
- Examined the dataset structure, columns, and data types.

### 2. Exploratory Data Analysis (EDA)
- Analyzed data distributions and summary statistics.
- Identified trends, patterns, and potential anomalies.
- Explored relationships between relevant variables.

### 3. Data Cleaning & Preparation
- Handled missing and duplicate values where appropriate.
- Corrected data types and inconsistent values.
- Prepared the dataset for further analysis.

### 4. SQL Analysis Using MySQL
- Loaded the cleaned data into a MySQL database.
- Wrote SQL queries to analyze customer behavior.
- Used filtering, aggregation, grouping, and joins where applicable to extract insights.

### 5. Power BI Dashboard
- Connected the prepared data to Power BI.
- Created interactive visuals, charts, and KPI summaries.
- Presented key customer behavior trends in an easy-to-understand format.

### 6. Report & Presentation
- Documented the analysis process and key findings in a report.
- Created a presentation using Gamma to communicate the project's insights and recommendations.

## How to Run

### Prerequisites
- Python 3.x
- Jupyter Notebook
- MySQL Server and MySQL Workbench
- Microsoft Power BI Desktop

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Amantiwari5015/Customer-Behavior-Analysis.git
   cd Customer-Behavior-Analysis
   ```

2. **Install Python libraries**
   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter
   ```

3. **Run the Python analysis**
   - Open Jupyter Notebook.
   - Load the dataset.
   - Run the notebook cells to perform EDA and data cleaning.

4. **Run SQL queries**
   - Start your MySQL Server.
   - Create the required database and import the cleaned dataset.
   - Open and execute the queries in the `sql/` folder.

5. **Open the Power BI dashboard**
   - Open the `.pbix` file in Power BI Desktop.
   - Configure the data source if required.
   - Refresh the data to view the dashboard.

6. **Review the deliverables**
   - Read the project report.
   - Open the final presentation to review the key insights and recommendations.
